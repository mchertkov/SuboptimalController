# CASE118 Stage 4 PIC/certificate package

This package continues directly from the frozen Stage-3A/Stage-3B case118 campaign. It contains no manuscript edits.

Start with `STAGE4_REPORT.md` and `results/stage4_pic_certificate_summary_final.csv`.

Run `python verify_stage4.py` for consistency checks.
