# MATPOWER case39 stochastic-control experiment

This directory is the complete numerical companion to the case39 section of the manuscript.

## What is reproduced

The experiment fixes the severe load-loss event used in the companion cycle-space paper: loading scale `alpha=4`, disappearance of the load at MATPOWER bus 20, and equal final generator balancing as the common post-event equilibrium.  The stochastic extension adds independent white nodal injection fluctuations and generator-only direct active-power feedback.

The directory contains the following completed experiment families:

1. deterministic transient regression and balancing-concentration stress test;
2. homogeneous and activity-scaled nodal-noise amplitude sweeps;
3. static balancing, droop, and scaled-LQR upper-bound policies;
4. H0--H3 generator-actuation hierarchy and dual PIC lower constructions;
5. PIC feedback projection onto the H3 LQR command;
6. smooth-barrier versus stopped failure-cost Feynman--Kac comparison;
7. deleted-noise curvature screen;
8. cycle-consistent terminal curvature enclosure;
9. first/second/third cellwise variation bounds;
10. graph-local policy truncation;
11. sample-and-hold, actuator lag, saturation and generator-dropout tests;
12. time-step convergence;
13. control inflation/completion: a curvature-free H3 PIC oracle using the physical all-bus noise.

## Directory map

- `notebooks/`: five narrative notebooks with equations, interpretation and result inspection; `04_control_inflation.ipynb` develops the new completion benchmark.
- `src/`: reusable nonlinear swing, PIC, actuation-hierarchy and certificate code.
- `cyclespace_base/`: deterministic companion-model code copied verbatim from the finalized cycle-space package.
- `results/`: machine-readable cached summaries used by the manuscript.
- `figures/`: PDF and PNG figures generated from `results/`.
- `scripts/make_figures.py`: regenerates every case39 manuscript figure from cached results.
- `scripts/recompute_notes.py`: documents the full heavy recomputation order.
- `tests/`: regression tests inherited from the certificate-development code.

## Immediate figure reproduction

From this directory:

```bash
python scripts/make_figures.py
```

This regenerates both PDF and PNG versions of all case39 figures without rerunning expensive Monte Carlo.

## Full recomputation

The deterministic base loader expects standard MATPOWER `case39.m`.  Put it in `cyclespace_base/data/` for fully offline use, or let `matpower_loader.py` obtain it when network access is available.  The heavy stochastic campaign should be rerun with fixed common-random-number seeds and the chosen production time step before replacing the cached tables.

The cached summaries are included deliberately: they make the paper and figures exactly reproducible immediately, while the Python source documents how each quantity is recomputed from the model.

## Certification status

The case39 campaign now contains two distinct PIC lower constructions.  The noise-deflated smooth PIC candidate has a rigorous positive terminal layer and positive representative compact-domain curvature diagnostics, but the whole interior compact continuum has not yet been enclosed; its `J-W_-` gap therefore remains a **candidate** nonlinear certificate gap.  The new control-inflated value is an automatic analytic subsolution because its residual is nonnegative virtual-control energy; however, the reported Feynman--Kac number is still a Monte Carlo estimate of that exact value and is not yet equipped with a rigorous finite-sample confidence correction.  Empirical cohesion-loss probabilities are also not yet replaced by a rigorous first-exit supermartingale bound.

## Reinforcement-planning extension (09-09)

The case39 campaign now also includes a physical-design interpretation of the completed control geometry.  This **does not replace** virtual control completion; it adds a second use of the same object.

New experiment families:

14. exact-PIC investment/performance frontier obtained by varying `lambda <= lambda_max`;
15. generator control-metric redesign at fixed total authority, including the closed-form noise-proportional allocation;
16. fixed robust versus scenario-specific/reconfigurable authority for homogeneous and activity-scaled noise;
17. sparse load-bus fast-flexibility reinforcement selected either by noise magnitude or by a dynamics-aware H4/LQR utilization proxy.

The new detailed notebook is `notebooks/06_reinforcement_planning.executed.ipynb`.  New reusable code is in `src/reinforcement_planning.py`; the main cached output is `results/reinforcement_planning.json`; the paper figures are generated by `scripts/make_reinforcement_planning_figures.py`.

The `effective_power_authority_MW` quantity in the cached results is a Gramian-to-power authority proxy, **not** a physical battery MW/MWh nameplate.  State of charge, energy duration, degradation, saturation/current limits and charging headroom remain separate design constraints.
